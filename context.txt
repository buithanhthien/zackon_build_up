# ZACKON ROBOT — PROJECT CONTEXT
# Last updated: 2026-04-24

## HARDWARE
- Robot: Zackon Mobile Robot (differential drive)
- MCU: ESP32 / STM32 — communicates via UDP port 8888 (micro-ROS)
- Odometry: wheel encoder only (STM32), topic: /odomfromSTM32
- IMU: not yet integrated (planned for future)
- LiDAR: dual (front + rear RPLIDAR), merged into /merged topic
- PC: AMD Ryzen 5 6600H, 6 cores / 12 threads

## ROS 2 STACK
- Package: view_robot_pkg (path: src/view_robot/)
- Build system: ament_python (colcon)
- Key launch files:
  - MAP_GENERATING.launch.py   → SLAM mapping mode
  - NAV2_BRINGUP.launch.py     → Full autonomous navigation
  - zackon_localization.launch.py
  - joystick.launch.py         → Manual drive (joy_linux only, no teleop node)

## PIPELINE (NAV2_BRINGUP)
ESP32/STM32 → micro_ros_agent (UDP:8888)
  → /odomfromSTM32
  → ekf_filter_node (robot_localization) → /odom + TF odom→base_link
LiDAR front+rear → filters → merge_lidar → /merged
AMCL → TF map→odom
Nav2 (MPPI + SmacPlanner2D) → /cmd_vel

## CONFIG FILES (src/view_robot/config/)
- mapper_params_online_async.yaml  — SLAM Toolbox settings
- ekf.yaml                         — EKF sensor fusion
- nav2_params.yaml                 — Full Nav2 stack (AMCL, MPPI, costmaps, etc.)

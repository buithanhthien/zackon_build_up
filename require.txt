enum class DockState

==============================

Trong constructor, sau nhom parameter hien tai, them cac dong sau:

// PREALIGN thresholds
prealign_y_threshold_ = declare_parameter<double>("prealign_y_threshold", 0.03);
prealign_yaw_threshold_ = declare_parameter<double>("prealign_yaw_threshold", 0.10);

// PREALIGN gains
k_prealign_y_ = declare_parameter<double>("k_prealign_y", 2.5);
k_prealign_yaw_ = declare_parameter<double>("k_prealign_yaw", 0.8);

// PREALIGN velocity limits
v_prealign_max_ = declare_parameter<double>("v_prealign_max", 0.08);
w_prealign_max_ = declare_parameter<double>("w_prealign_max", 0.5);

==============================
4. THEM HAM publishPrealignMotion()
==============================

Dat ham nay gan cac ham publishStop(), publishSearchMotion(), ...

void publishPrealignMotion(double x, double y, double yaw)
{
  geometry_msgs::msg::Twist cmd;

  // Muc tieu:
  // - uu tien giam |y|
  // - yaw la phu
  // - co the tien/lui/xoay nhe de dua pose ve dep

  // Dieu khien goc:
  double w_cmd = -k_prealign_y_ * y - k_prealign_yaw_ * yaw;
  w_cmd = clamp(w_cmd, -w_prealign_max_, w_prealign_max_);

  // Dieu khien linear:
  // Neu lech y qua lon thi giam linear de tranh robot vua lao vua lech
  double v_cmd = 0.0;

  if (std::abs(y) < 0.08) {
    // Cho phep chuyen dong nhe de ho tro dua y ve dep
    // x < 0 nghia la dock dang o phia sau robot
    // o PREALIGN chi cho toc do nho
    if (x < -0.55) {
      // Robot dang con xa, cho lui nhe
      v_cmd = -0.04;
    } else if (x > -0.40) {
      // Robot dang hoi gan qua, cho tien nhe len de co khong gian chinh
      v_cmd = 0.04;
    } else {
      v_cmd = 0.0;
    }
  } else {
    // Neu y lech qua lon, uu tien xoay/chinh hon la di chuyen
    v_cmd = 0.0;
  }

  v_cmd = clamp(v_cmd, -v_prealign_max_, v_prealign_max_);

  cmd.linear.x = v_cmd;
  cmd.angular.z = w_cmd;

  RCLCPP_INFO_THROTTLE(
    get_logger(), *get_clock(), 200,
    "[rear_docking_ctrl] PREALIGN pose=(x=%.3f y=%.3f yaw=%.3f) cmd=(vx=%.3f wz=%.3f)",
    x, y, yaw, cmd.linear.x, cmd.angular.z);

  cmd_pub_->publish(cmd);
}


==============================
5. THEM LOGIC CHUYEN STATE PREALIGN
==============================

Trong ham controlLoop(), giu nguyen tat ca logic hien tai:
- SAFETY CHECK
- DOCKED HOLD
- SEARCH
- has_dock_pose
- pose timeout
- odom check
- invalid x >= 0
- DOCKED ZONE CHECK
- TRACK logic cu

CHI THEM 1 KHOI LOGIC MOI NGAY SAU KHI DA CO:
- x
- y
- yaw
- va da qua duoc check x >= 0

Tuc la sau doan nay:

const double x = last_dock_pose_.pose.position.x;
const double y = last_dock_pose_.pose.position.y;

const double yaw = normalizeAngle(
  2.0 * std::atan2(
    last_dock_pose_.pose.orientation.z,
    last_dock_pose_.pose.orientation.w));

if (x >= 0.0) {
  RCLCPP_WARN_THROTTLE(
    get_logger(), *get_clock(), 500,
    "[rear_docking_ctrl] Invalid rear-docking pose: x=%.3f (expected negative)", x);
  publishStop();
  publishDockedStatusIfChanged(0);
  docked_counter_ = 0;
  return;
}

THEM DOAN NAY NGAY SAU NO:

// ===============================
// PREALIGN GATE
// ===============================
// Neu pose chua dep thi dua qua PREALIGN.
// Khi pose dep roi thi tra ve TRACK hien tai.

const bool need_prealign =
  (std::abs(y) > prealign_y_threshold_) ||
  (std::abs(yaw) > prealign_yaw_threshold_);

if (need_prealign) {
  state_ = DockState::PREALIGN;
} else {
  if (state_ == DockState::PREALIGN) {
    RCLCPP_INFO(
      get_logger(),
      "[rear_docking_ctrl] PREALIGN completed -> TRACK MODE");
  }
  state_ = DockState::TRACK;
}

if (state_ == DockState::PREALIGN) {
  publishDockedStatusIfChanged(0);
  docked_counter_ = 0;   // dang tinh chinh thi chua duoc tinh docked
  publishPrealignMotion(x, y, yaw);
  return;
}


==============================
6. KHONG SUA LOGIC TRACK CU
==============================

Sau khi them PREALIGN gate o tren, GIU NGUYEN phan duoi nhu hien tai:
- DOCKED ZONE CHECK
- Reverse speed from longitudinal error
- Angular correction
- badly_misaligned
- cmd.linear.x = -v_mag
- cmd.angular.z = w_cmd
- publish cmd_vel

Tuc la TRACK hien tai cua ban van y nguyen.


==============================
7. KHONG SUA dockPoseCallback()
==============================

Giu nguyen logic hien tai cua dockPoseCallback(), vi ban noi chi muon them phan tinh chinh chu khong sua logic cu.

Tuc la van de nguyen:

void dockPoseCallback(const geometry_msgs::msg::PoseStamped::SharedPtr msg)
{
  if (state_ == DockState::DOCKED) {
    return;
  }

  last_dock_pose_ = *msg;
  has_dock_pose_ = true;
  last_dock_pose_time_ = now();

  if (state_ == DockState::SEARCH) {
    state_ = DockState::TRACK;

    RCLCPP_INFO(
      get_logger(),
      "[rear_docking_ctrl] Dock pose reacquired -> TRACK MODE");
  }
}

Khong bat buoc phai sua doan nay.
ControlLoop se tu chuyen sang PREALIGN neu pose chua dep.

==============================
10. FLOW SAU KHI TICH HOP
==============================

SEARCH
  -> khi co dock pose

Neu y/yaw chua dep
  -> PREALIGN

Khi y/yaw dep
  -> TRACK (logic cu)

Khi dat docked zone va confirm du so lan
  -> DOCKED

DOCKED
  -> giu stop, publish status 1


==============================
11. DIEU QUAN TRONG NHAT
==============================

Ban KHONG CAN doi ten TRACK.
Ban KHONG CAN sua logic docking cu.
Ban CHI THEM:
- 1 state PREALIGN
- 1 ham publishPrealignMotion()
- 1 doan gate truoc TRACK

Toan bo logic cu phia sau van duoc giu nguyen.
